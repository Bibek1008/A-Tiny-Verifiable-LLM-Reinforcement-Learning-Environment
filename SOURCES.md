# Sources


## RAGEN

Wang et al., **RAGEN: Understanding Self-Evolution in LLM Agents via
Multi-Turn Reinforcement Learning**.

Paper:
https://arxiv.org/abs/2504.20073

Official repository:
https://github.com/mll-lab-nu/RAGEN

RAGEN is the main research reference motivating the executable
environment + multi-turn reinforcement-learning setup used in this project.
