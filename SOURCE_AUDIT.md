# Source and Attribution

## Reference project


The original reference project was inspired by:

- Wang et al., **RAGEN: Understanding Self-Evolution in LLM Agents via
  Multi-Turn Reinforcement Learning**
- arXiv: https://arxiv.org/abs/2504.20073
- Official implementation:
  https://github.com/mll-lab-nu/RAGEN

## What this project uses

The project retains the following ideas and components from the reference
implementation:

- An autoregressive policy interacting with an executable environment.
- A deterministic Sokoban environment.
- Exact BFS-based verification.
- Generated behavior-cloning examples.
- Online reinforcement learning from executable trajectories.
- Held-out evaluation of the learned policy.

## Project implementation

The project is implemented and organized as a small local LLM-RL environment.

Core components include:

- Sokoban environment and transition rules.
- Exact BFS solver.
- Symbolic tokenizer.
- Small decoder-only Transformer.
- Supervised behavior-cloning stage.
- REINFORCE training.
- Evaluation and experiment reporting.

## Experimental results

Results reported in this repository are generated from runs performed for this
project.

Original/reference-project results are not presented as results generated by
this project.
